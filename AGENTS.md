# X-Agent repository guidance

1. Read `CONTEXT/ROUTER.md` first. Use its indexes to choose the smallest node that answers a question.
2. `CONTEXT/index*.md` files are generated by `scripts/build-graph-index.mjs`; never hand-edit them. Run `make graph-index` after adding or renaming a context node, and keep `make graph-index-check` green.
3. Treat `CONTEXT/product/CONTENT_STUDIO_SPEC.md` as the binding product contract. Handoffs record history; the issue tracker records work and dependencies.
4. Run the existing verification commands before handing off changes:

```sh
python3 -m unittest -v
python3 ai_digest.py --self-test
python3 -m py_compile ai_digest.py x_auth.py test_ai_digest.py
```
